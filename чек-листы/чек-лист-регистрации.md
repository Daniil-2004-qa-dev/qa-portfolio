# Чек-лист тестирования формы регистрации

## 1. Общая информация

- **Объект тестирования:** форма регистрации нового пользователя.
- **Цель:** проверить корректность регистрации, валидацию полей и обработку ошибок.
- **Предварительные условия:** пользователь не авторизован, тестовый email ранее не использовался.

## 2. Позитивные проверки

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| REG-001 | Регистрация с корректными данными во всех полях | Аккаунт успешно создан |
| REG-002 | Ввод корректного email | Email принимается системой |
| REG-003 | Ввод пароля, соответствующего требованиям | Пароль принимается системой |

## 3. Негативные проверки

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| REG-004 | Отправка пустой формы | Отображаются сообщения об обязательных полях |
| REG-005 | Ввод email в некорректном формате | Отображается сообщение об ошибке |
| REG-006 | Ввод пароля короче минимальной длины | Отображается сообщение о требованиях к паролю |
| REG-007 | Ввод несовпадающих пароля и подтверждения | Регистрация не выполняется |
| REG-008 | Регистрация с уже существующим email | Отображается сообщение, что аккаунт уже существует |

## 4. Дополнительные проверки

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| REG-009 | Удаление введённых данных из обязательного поля | Система корректно обрабатывает пустое поле |
| REG-010 | Повторное нажатие кнопки регистрации | Не создаются дублирующие аккаунты |

## 5. Примечание

Ожидаемые результаты необходимо сверять с требованиями конкретного продукта. Проверки пароля, email и повторной отправки зависят от правил реализации регистрации.
